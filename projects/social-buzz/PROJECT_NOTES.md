# Social Buzz — Content Popularity Analysis

**Business question:** Which five content categories have the largest aggregate popularity?

**Workflow:** identify required datasets → clean data → extract and merge → aggregate reaction scores → rank categories → communicate findings.

**Key result:**
- Healthy eating — 71,168
- Technology — 69,339
- Food — 68,738
- Science — 57,783
- Animals — 49,619

The original presentation contains the project explanation and the top-five result table. The visualization folder contains both a direct screenshot of the original slide and a chart reconstructed from the supplied workbook values.
